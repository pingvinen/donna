## Problem

After meetings, follow-up actions need to be captured in the task list. These actions may be in handwritten notes or meeting transcripts (e.g. Microsoft Teams). Currently there is no skill to ingest these sources.

## Solution

Create a skill that can process meeting transcriptions and human notes (both are essentially text files) to extract actionable tasks and add them to the daily journal or TODO list.
