## Problem

The skills table in README.md has grown long and messy, making it hard to scan and find relevant commands.

## Solution

Add column-spanning rows to the table that group related commands into categories such as: setup, tasks and flow, tools, and others. This improves scannability without changing the underlying skill structure.
