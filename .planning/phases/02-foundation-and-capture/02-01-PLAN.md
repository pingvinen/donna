  <name>Task 2: Replace setup workflow with real interactive setup logic</name>
  <files>workflows/setup.md</files>
  <action>
    Replace `workflows/setup.md` entirely with the real setup workflow. Follow the workflow file template from RESEARCH.md Pattern 1.

    The workflow must implement these steps:

    **Step 1 — Banner:** Print `━━━ DONNA ▸ Setup ━━━`

    **Step 2 — Check existing config:** Read `~/.config/donna/config.md`.
    - If it exists: enter re-run mode (Step 2a)
    - If it does not exist: proceed to first-run flow (Step 3)

    **Step 2a — Re-run menu:** Use AskUserQuestion to offer:
    1. Change storage repo path
    2. View current config
    3. Reset (start over — deletes config, re-runs full setup)
    4. Cancel
    - Option 1: ask for new path, validate it, update config.md, print summary
    - Option 2: display current config.md contents, then stop
    - Option 3: delete `~/.config/donna/config.md`, proceed to Step 3
    - Option 4: print "Setup cancelled." and stop

    **Step 3 — Ask for storage repo path:** Use AskUserQuestion to ask the user for the path to their storage repo. Explain: "This is a local git repository where Donna stores your daily journal, tasks, and configuration."

    **Step 4 — Validate and init repo:**
    - Expand `~` in the path (use Bash: `echo <path>` or handle tilde)
    - If the path is an existing git repo: use it as-is
    - If the path exists but is not a git repo: run `git -C <path> init`
    - If the path does not exist: run `mkdir -p <path>` then `git -C <path> init`

    **Step 5 — Create storage structure:**
    - Run `mkdir -p <repo>/daily`
    - Do NOT create role.md, recurring.md, tools.md, people.md (those belong to later phases per locked decisions)
    - Print `✓ Created daily/ directory`

    **Step 6 — Write bootstrap config:**
    - Run `mkdir -p ~/.config/donna` via Bash
    - Write `~/.config/donna/config.md` with YAML frontmatter format:
    ```markdown
    ---
    storage_repo: /absolute/path/to/repo
    auto_push: false
    ---

    # Donna Configuration

    This file is managed by `/donna:setup`. All Donna skills read this file to find your storage repo.
    ```
    - Print `✓ Wrote config at ~/.config/donna/config.md`

    **Step 7 — Initial commit:**
    - Run `git -C <repo> add -A`
    - Check `git -C <repo> status --porcelain` — if nothing to commit, skip
    - Run `git -C <repo> commit -m "donna(setup): initialize storage"`
    - Print `✓ Committed initial structure`

    **Step 8 — Summary:**
    Print:
    ```
    ✓ Donna is ready!

    Storage repo: <path>
    Config: ~/.config/donna/config.md

    Next steps:
      - Run /donna:add-task to capture your first task
      - Run /donna:done to mark tasks complete
    ```

    IMPORTANT: The workflow is a Markdown file with instructions for Claude Code — it does NOT contain executable code. It contains natural language steps wrapped in `<step>` tags that Claude interprets at runtime. Use the exact step/tag structure from the existing setup.md and RESEARCH.md patterns.
