    1. Create src/installer.cjs exporting async `run(options)` where options allows overriding homeDir for testing (defaults to os.homedir()). The function orchestrates:
       a. Print banner via output.banner()
       b. Determine donnaDir = `{homeDir}/.donna/`
       c. Create donnaDir if it doesn't exist (fs.mkdirSync recursive)
       d. Read current version via version.readVersion(donnaDir)
       e. Determine package version from require('../package.json').version
       f. If current version matches package version and no pending migrations: print "Already up to date at {version}" via output.info(), return early
       g. If upgrading (current version exists but differs): print upgradeHeader(oldVersion, newVersion)
       h. Run migrations via migrator.runMigrations(migrationsDir, donnaDir, lastMigration)
       i. For each successful migration result: print migrationLine(description)
       j. If any migration failed: print fail() with error, write version.md with last successful migration number, throw error
       k. Detect providers via providers.detectProviders(homeDir)
       l. For each provider: copy stubs using fs.cpSync(provider.stubSource, path.join(provider.getStubTarget(homeDir), 'donna'), { recursive: true }), print success("Copied donna:setup to {target}")
       m. If no providers detected: print info("No supported AI providers detected"), info("Install Claude Code and re-run to add donna skills")
       n. Copy workflows/ directory to donnaDir/workflows/ using fs.cpSync, print success("Installed workflows to ~/.donna/workflows/")
       o. Write version.md via version.writeVersion(donnaDir, packageVersion, lastMigrationNum)
       p. Print success("Version {version} installed")
       q. Print info("Run /donna:setup in Claude Code to get started.")
    2. Create bin/install.cjs with shebang `#!/usr/bin/env node`, requires ../src/installer.cjs, calls run().catch() with error output and process.exit(1).
    3. Run `chmod +x bin/install.cjs`.
