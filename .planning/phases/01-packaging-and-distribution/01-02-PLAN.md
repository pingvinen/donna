<task type="auto">
  <name>Task 2: Create provider detection module</name>
  <files>src/providers/claude-code.cjs</files>
  <action>
    Create `src/providers/claude-code.cjs` that exports a provider object:

    ```javascript
    const fs = require('fs');
    const path = require('path');
    const os = require('os');

    module.exports = {
      name: 'Claude Code',
      detect() {
        return fs.existsSync(path.join(os.homedir(), '.claude'));
      },
      stubSource: path.join(__dirname, '..', '..', 'stubs', 'claude-code'),
      stubTarget: path.join(os.homedir(), '.claude', 'commands'),
    };
    ```

    The provider detection pattern is intentionally simple -- just check if `~/.claude/` exists. The `stubSource` points to the package's `stubs/claude-code/` directory (where donna command stubs live). The `stubTarget` points to `~/.claude/commands/` (where Claude Code discovers slash commands).

    Note: `stubSource` and `stubTarget` are computed at module load time, which is fine for a one-shot installer script.

    Also create a `src/providers/index.cjs` that aggregates all providers:
    ```javascript
    const claudeCode = require('./claude-code.cjs');
    const ALL_PROVIDERS = [claudeCode];
    function detectProviders() {
      return ALL_PROVIDERS.filter(p => p.detect());
    }
    module.exports = { detectProviders, ALL_PROVIDERS };
    ```
