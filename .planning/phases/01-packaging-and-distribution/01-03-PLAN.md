    **Step 2: Create installer orchestration**

    Create `src/installer.cjs` exporting async `run()` function. The installer flow:

    1. Call `output.banner()`
    2. Resolve `donnaDir = path.join(os.homedir(), '.donna')`
    3. Read existing version: `version.readVersion(donnaDir)`
    4. Determine package version from `require('../package.json').version`
    5. **Fresh install path** (no existing version):
       - Create donnaDir: `fs.mkdirSync(donnaDir, { recursive: true })`
       - Run all migrations via `migrator.runMigrations(migrationsDir, donnaDir, 0)`
       - If any migration failed: call `output.fail()` with error, write version.md with last successful migration, exit with error
       - Copy workflows from package's `workflows/` to `donnaDir/workflows/` using `fs.cpSync` with `{ recursive: true, force: true }`
       - Detect providers via `providers.detectProviders()`
       - For each detected provider: copy stubs from `provider.stubSource` to `provider.stubTarget` using `fs.cpSync({ recursive: true, force: true })`
       - Write version.md via `version.writeVersion(donnaDir, { version: pkgVersion, lastMigration: highestMigrationNum })`
       - Print success messages for each step
    6. **Upgrade path** (existing version < package version):
       - Run pending migrations (from `existing.lastMigration`)
       - Print upgrade changelog via `output.upgradeLog()`
       - Copy updated workflows and stubs (overwrite managed files)
       - Update version.md via `version.updateVersion()`
    7. **Already current path** (existing version == package version):
       - Print `info("Already at version X.Y.Z -- nothing to do")`
       - Still copy stubs and workflows (in case files were deleted) to ensure idempotency
    8. **No providers detected:**
       - Print `info("No supported AI providers detected")`
       - Print `info("Shared runtime installed to ~/.donna/")`
       - Print `info("Re-run after installing Claude Code (or another supported provider)")`

    Final line: Print `info("Run /donna:setup in Claude Code to get started.")`

    Create `bin/install.cjs` with shebang line:
    ```javascript
    #!/usr/bin/env node
    'use strict';
    const { run } = require('../src/installer.cjs');
    run().catch(err => {
      console.error('\n  ✗ Installation failed:', err.message);
      process.exit(1);
    });
    ```

    - **No provider test:** Run installer with empty providers list, verify donnaDir created but no stub target written, no error thrown

    To make the installer testable, `src/installer.cjs` should accept an optional config/options object that overrides `donnaDir`, `migrationsDir`, and providers list. The `run()` function uses defaults (real paths) when no overrides given, but tests pass overrides pointing to temp dirs:
