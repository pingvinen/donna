  <name>Task 2: Create version tracking module with tests</name>
  <files>src/version.cjs, test/version.test.cjs</files>
  <behavior>
    - Test: readVersion returns null when version.md doesn't exist
    - Test: readVersion parses version string from markdown format
    - Test: readVersion parses lastMigration number from markdown format
    - Test: readVersion parses installed and updated timestamps
    - Test: writeVersion creates version.md with correct markdown format
    - Test: writeVersion on fresh install sets both installed and updated to same timestamp
    - Test: updateVersion preserves original installed timestamp but updates the updated timestamp
    - Test: round-trip: write then read returns same data
  </behavior>
  <action>
    1. Create `test/version.test.cjs` using `node:test` and `node:assert`. All tests must use a temp directory (via `fs.mkdtempSync`) as the donna dir -- never touch real `~/.donna/`. Tests:
       - `readVersion(nonexistentDir)` returns `null`
       - `writeVersion(tmpDir, { version: '0.1.0', lastMigration: 1 })` creates `version.md`
       - Reading back the written file returns `{ version: '0.1.0', lastMigration: 1, installed: <timestamp>, updated: <timestamp> }`
       - `updateVersion(tmpDir, { version: '0.2.0', lastMigration: 2 })` preserves original `installed` timestamp but sets new `updated` timestamp
       - Round-trip consistency test
    2. Run tests -- they MUST fail.
    3. Create `src/version.cjs` exporting:
       - `readVersion(donnaDir)` -- reads `{donnaDir}/version.md`, parses markdown format, returns `{ version, lastMigration, installed, updated }` or `null` if file doesn't exist.
       - `writeVersion(donnaDir, { version, lastMigration })` -- writes fresh version.md with both installed and updated set to `new Date().toISOString()`.
       - `updateVersion(donnaDir, { version, lastMigration })` -- reads existing to preserve `installed` timestamp, updates `version`, `lastMigration`, and `updated` timestamp.

       Version file format (from research):
       ```
       # Donna

       - **Version:** 0.1.0
       - **Last migration:** 001
       - **Installed:** 2026-03-14T10:00:00.000Z
       - **Updated:** 2026-03-14T10:00:00.000Z
       ```

       Use regex parsing for read: `/\*\*Version:\*\* (.+)/`, `/\*\*Last migration:\*\* (\d+)/`, `/\*\*Installed:\*\* (.+)/`, `/\*\*Updated:\*\* (.+)/`.
       Use `String(lastMigration).padStart(3, '0')` for the migration number display.
    4. Run tests -- they MUST pass.
  </action>

  </verify>
